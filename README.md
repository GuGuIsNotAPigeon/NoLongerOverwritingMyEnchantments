# No Longer Overwriting My Enchantments (NLOME)

不再刷过我的附魔书！保护村民交易中你收藏的附魔书，防止被交易刷新覆盖。

## 功能

- **收藏管理**：在配置界面（默认按 `K`，也可从 Mod Menu 进入；按键可在“按键设置”里改）中添加你想要的附魔（如经验修补 Mending）。
- **工作站保护**：村民贩卖你收藏的附魔书时，破坏其工作站不会立刻刷新掉这本附魔书，而会重设其职业或刷新交易（可配置次数阈值）。
- **交易刷新拦截**：拦截通过快捷键/按钮触发的村民交易刷新（如 Trade Cycling），只要村民还在出售收藏的附魔书，刷新会被阻止，并在交易界面以 toast 提示剩余次数；达到阈值后放行刷新。

## 运行环境

- **仅客户端 / 单人**：`fabric.mod.json` 声明 `environment: "client"`，且没有任何网络同步，无法用于专用服务器。
- **配置入口**：游戏内默认按 `K` 打开配置界面；装了 Mod Menu 也会出现在其模组列表中。按键冲突时可在“按键设置 → 不再刷过我的附魔书”里重绑。
- 可选：Trade Cycling（开启其交易拦截集成）。

## 支持版本

当前分支对应 Minecraft 1.21.5，其余 1.21.x 版本由独立分支维护：

| 分支 | Minecraft 版本 |
| --- | --- |
| `main` | 1.21.11 |
| `1.21.9-1.21.10` | 1.21.9 |
| `1.21.5-1.21.8` | 1.21.5 |
| `1.21.1-1.21.4` | 1.21.1 |

每个分支均为仓库根目录下的单一工程，切换分支后即可构建。

## 构建

```sh
./gradlew build
```

产物位于 `build/libs/nlome-1.0.2.jar`。
